OAuth 로그인과 세션 갱신

  • signInWithOAuth({ provider, options: { redirectTo: `${origin}/auth/callback` } }). provider는 github 또는 google.
  • 콜백은 exchangeCodeForSession(code) 성공 시 ${origin}${next}(기본 /)로, 실패하거나 code가 없으면 /sign-in?error=auth_callback_error로 보냄. SignInForm이 이 쿼리를 읽어 에러를 표시함.
  • 이메일 로그인은 signInWithPassword 뒤 router.push("/")와 router.refresh()만 하고 콜백은 거치지 않음.
  • src/proxy.ts의 matcher(정적 자산 제외)에 걸리는 모든 요청에서 updateSession()이 auth.getUser()로 토큰을 갱신하고 응답 쿠키를 다시 set함.
  • AuthProvider는 마운트 시 getUser()로 초기화하고, 이후 onAuthStateChange로 setUser/setLoading(false)를 호출함.
