포스트 발행 상태와 정렬일

  • posts.sort_date는 GENERATED ALWAYS AS (COALESCE(published_at, created_at)) STORED. 목록은 (sort_date desc, created_at desc, id desc)로 정렬됨.
  • 재발행 시 published_at이 갱신되어 목록 상단으로 올라감. 반대로 draft로 내려도 published_at은 유지되어 sort_date가 마지막 발행일로 남음.
  • RLS posts_select: status = 'published'이거나 작성자(author) 또는 admin만 조회 가능.
  • 삭제 경로 두 가지: 관리자 목록의 deletePost(app/admin/posts/actions.ts)는 post_tags·post_likes·post_views·bookmarks를 먼저 지우고, 상세 페이지의 deletePost(app/posts/[slug]/actions.ts)는 Storage 이미지를 지운 뒤 FK cascade에 맡김.
