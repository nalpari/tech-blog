Database schema · techlog

DB 스키마

  • 생략한 테이블: bookmarks(user_id·post_id 모두 CASCADE), post_views(post_id CASCADE, user_id SET NULL, SELECT는 admin만).
  • sort_date = GENERATED ALWAYS AS (COALESCE(published_at, created_at)) STORED. 목록 정렬 (sort_date, created_at, id) desc와 인덱스 키가 일치해야 함.
  • RPC(SECURITY DEFINER): toggle_post_like(post_slug, liker_id) → post_likes 삽입/삭제 + like_count 증감, increment_post_view_count(post_slug, viewer_id) → post_views 기록 + view_count 증가.
  • 트리거: on_auth_user_created → handle_new_user()가 auth.users 가입 시 profiles 행 생성. posts·profiles에는 update_updated_at 트리거.
  • admin/posts/actions.ts의 deletePost는 CASCADE가 있어도 post_tags·post_likes·post_views·bookmarks를 먼저 수동 삭제함.
