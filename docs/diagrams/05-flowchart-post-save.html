포스트 저장 Server Action 흐름

  • 근거: src/app/posts/new/actions.ts의 createPost. slug는 입력값이 없으면 generateSlug(title)로 만들고, 중복 조회에서 PGRST116(행 없음) 외의 오류는 error로 반환함.
  • 그림에서 뺀 경로: posts insert 실패 시 { error: 포스트 저장에 실패했습니다 } 반환, 예상 못 한 예외는 catch에서 error로 변환(isRedirectError는 다시 throw).
  • updatePost(src/lib/post-actions.ts)와의 차이: 자기 자신(neq("id", postId))을 빼고 slug 중복을 검사함 · 태그는 post_tags delete 후 insert로 교체 · 태그 실패 시 정리 로직 없음 · draft→published로 바뀔 때만 published_at을 설정 · draft로 저장하면 /admin/posts로 redirect.
