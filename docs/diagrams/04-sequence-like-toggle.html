좋아요 토글과 조회수

  • LikeButton은 비로그인이면 요청 없이 /sign-in으로 이동하고, 로그인 상태면 낙관적 업데이트 후 POST를 보냄. 401이나 오류가 오면 되돌림.
  • slug가 SLUG_PATTERN과 맞지 않거나 200자를 넘으면 400. RPC 결과가 null이면 404, RPC 오류는 500.
  • toggle_post_like(post_slug, liker_id)는 post_likes에 행이 있으면 delete하고 like_count - 1(최소 0), 없으면 insert하고 like_count + 1. 반환값은 {liked, likeCount}.
  • increment_post_view_count(post_slug, viewer_id)는 post_views에 행을 넣고 view_count + 1. view 라우트도 auth.getUser()로 viewer_id를 채우지만(비로그인은 null) 메시지 예산 때문에 다이어그램에서는 뺐음.
  • 마운트 시 좋아요 상태를 조회하던 GET /like는 제거됐음. liked는 서버 렌더가 getLikedPostIds로 채워 initialLiked로 내려주므로 클라이언트는 토글 시에만 요청을 보냄.
  • like_count는 post:<slug> 캐시(60초)를 타므로, 토글 직후 새로고침하면 하트는 채워진 채 숫자만 옛 값일 수 있음. Route Handler에서는 updateTag를 쓸 수 없다(E872).
