홈 무한 스크롤 페이지네이션

  • limit + 1 트릭: POSTS_PER_PAGE(6)보다 1개 더 요청해 7번째 행이 있으면 hasMore = true이고, 응답에는 6개만 담음. /api/posts는 limit를 POSTS_PER_PAGE로 상한 처리함.
  • 정렬 불변식: sort_date = COALESCE(published_at, created_at)(generated column), 정렬 순서는 (sort_date desc, created_at desc, id desc). 부분 인덱스는 posts_published_sort_idx … WHERE status = 'published'.
  • offset 기반이라 로드 사이에 새 글이 발행되면 경계가 밀릴 수 있어서, PostGrid가 slug 기준으로 중복을 제거한 뒤 append함.
